# Translation review

English is the working source. Amharic, Somali and Afaan Oromo strings are best-effort drafts added 2026-11-15. A native speaker should review every string for tone, spelling, gaming terminology, financial terminology and accessibility before the app is published. No live-money or payment terms are approved for release.

Files: `apps/web/src/i18n/en.json`, `am.json`, `so.json`, `om.json`. Run `npm run check:i18n` after editing to confirm the four files have the same keys.
